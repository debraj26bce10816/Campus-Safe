# CAMPUS SAFE - Project Statement

## Problem Statement

Students and other campus users may face situations such as emergencies, lost belongings, found items, or problems related to campus facilities.

Without a simple reporting system, these issues may be difficult to record and organize.

Campus Safe is designed as a simple Python-based system that allows users to submit and view different types of campus-related reports through a menu-driven interface.

## Scope of the Project

The project focuses on providing basic reporting and searching functionality for campus safety and support.

The system includes:

- Emergency reporting
- Lost-item reporting
- Found-item reporting
- Campus complaint submission
- Complaint priority assignment
- Lost-item searching
- Viewing individual report categories
- Viewing all reports
- Counting the number of reports

The current project is a command-line application and stores information temporarily in Python lists while the program is running.

It does not currently include:

- A database
- User accounts or authentication
- A graphical user interface
- Online/cloud storage
- Email or SMS notifications
- Automatic communication with campus authorities

## Target Users

The intended users include:

- Students
- Teaching staff
- Non-teaching staff
- Campus visitors
- Campus support personnel

The project is particularly useful for users who need a simple way to record campus-related incidents, lost and found items, or complaints.

## High-Level Features

### 1. Emergency Reporting

Users can report an emergency by providing their name, emergency type, location, and description.

### 2. Lost Item Reporting

Users can record information about an item they have lost, including where it was last seen and a description.

### 3. Found Item Reporting

Users can report an item they have found and provide its location and description.

### 4. Complaint Submission

Users can submit complaints about campus facilities or services.

### 5. Complaint Priority

The system assigns a basic priority according to the complaint category:

- Security: HIGH
- Electricity: HIGH
- Water: MEDIUM
- Other categories: NORMAL

### 6. Lost Item Search

Users can search the stored lost-item reports by entering an item name or part of the item name.

### 7. Report Viewing

The system allows users to view:

- Emergency reports
- Lost items
- Found items
- Complaints
- All reports

### 8. Report Counting

The system displays the total number of emergency reports, lost items, found items, and complaints.

## Expected Outcome

The expected outcome is a simple and easy-to-use Python application that demonstrates how basic programming concepts can be used to create a campus safety and support reporting system.
